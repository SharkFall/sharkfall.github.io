前情提要
#

关键词: Arm64 Mac 编译 Pixel 6 内核及内核模块 rwProcMem33, eBPF环境

上一篇 Arm64 Mac DIY Pixel 6 内核踩坑笔记 - 0x1 编译出的内核无法使用, 再次挑战

这一篇从头来过, 再次记录一下踩坑过程, 希望能帮助到屏幕前的你

我的设备是:

  • Pixel 6 Android 14 (AP2A.240905.003.F1, Sep 2024) -> 镜像下载
  • Mac Pro M5 Max
  • Docker amd64 ubuntu 22.04 (Docker 部署参考上一篇)

使用 Repo 下载内核源码
#

下载 Repo 工具
# 

curl https://storage.googleapis.com/git-repo-downloads/repo > /usr/local/bin/repo
chmod +x /usr/local/bin/repo

配置 Repo 镜像
#

这里参考 将rwProcMem33编译进安卓内核, 使用清华大学的镜像

有魔法直接继续

下载源码
#

Danger
  • 注意一点, 请先进入你想要下载的AOSP的地址, 看看仓库中的default.xml文件,
  • 重点关注 <project path=“build” name=“kernel/build” , 如果 revision 的值为 main,
  • 请千万不要下载, 否则你就会发现下载下来之后根本无法build!!, 这是由于build仓库和内核源码仓库不同步导致的
  • 引用自 Arm64 Mac DIY Pixel 6 内核踩坑笔记 - 0x1

分支是 android-gs-raviole-5.10-android14-qpr3, 确认分支参考-> [上一篇]

使用 build.sh 进行编译
#

单独写一份内核配置, 只写我们需要的

cat > private/gs-google/arch/arm64/configs/shark.fragment << 'EOF'
CONFIG_IKHEADERS=y
CONFIG_HAVE_KPROBES=y
CONFIG_KPROBES=y
CONFIG_KPROBE_EVENT=y
CONFIG_HAVE_HW_BREAKPOINT=y
CONFIG_HAVE_ARCH_TRACEHOOK=y
EOF

指定编译配置 build.config.gki.aarch64 路径和内核配置 shark.fragment 路径

BUILD_CONFIG=private/gs-google/build.config.gki.aarch64 \
GKI_DEFCONFIG_FRAGMENT=private/gs-google/arch/arm64/configs/shark.fragment \
LTO=thin build/build.sh -j$(nproc --all) 2>&1 | tee build.log
