前情提要
#

关键词: Arm64 Mac 编译 Pixel 6 内核及内核模块 rwProcMem33, eBPF环境

这一篇不适合高版本, 但低版本内核可以参考

我的设备是:

  • Pixel 6 Android 14 (AP2A.240905.003.F1, Sep 2024) -> 镜像下载
  • Mac Pro M5 Max

Docker 部署 amd64 Ubuntu
#

这里是第一个坑

Google 已经停止维护 Mac 上的工具链, 只能自己编译或寻找公开可用的

在用 Docker 之前也挣扎过, 想直接在 Mac 本机编译, 奈何没有找到合适的交叉编译器, 放弃 ~~~

安装过 VMWare 运行 arm64 Ubuntu 22.04, 问题并没有解决, 仍然没有合适的 arm64 linux 的交叉编译器

最后 Docker 部署运行 amd64 ubuntu 22.04 完美成功, 没想到性能损失微乎其微, 感谢 Docker, 感谢开源 !

部署 Docker 也是非常傻瓜式, 安装 Docker Desktop 并启动, 再打开 shell

没有魔法的话, 可以在设置配置镜像yuan

下载并启动镜像
#

  • 命令详解
    • -name ubuntu 推荐设置, 下面会很方便
    • –platform linux/amd64 一定要设置, 工具链是适用 amd64 架构的
    • -v path:path 是映射本机文件夹到容器, 相当于共享文件夹
docker run -it \
    --name ubuntu \
    --platform linux/amd64 \
    -u root \
    --restart always \
    -v /Users/sharkfall/WorkPlace/docker/workplace:/workplace \
    ubuntu:22.04
  • 启动容器, 并打开容器的 shell, 这里的 ubuntu 就是上面 –name 设置的容器名
docker start ubuntu
docker exec -it ubuntu bash
  • 不用了直接退出 Docker, 容器会自动关闭, 或者
docker stop ubuntu

Tip

Android toolchain 版本命名规则：

  • r450784 # 第一个版本 (a, 省略)
  • r450784b # 第二个版本
  • r450784c # 第三个版本
  • r450784d # 第四个版本
  • r450784e # 第五个版本 ← 我们需要的

在 Google prebuilts 直接找 r450784 注意这里没有最后的 e

一键编译
#

没有问题, 开始编译, 直接掏出我的一键编译脚本

cat > build.sh << 'EOF'
export ARCH="arm64"
export SUBARCH="arm64"
# 这里clang根据情况配置
export CLANG="/workplace/clang-r450784/clang-r450784c/bin"
export PATH="$PATH:$CLANG"
export CC="clang"
export LLVM=1
export LLVM_IAS=1
export CLANG_TRIPLE="aarch64-linux-gnu-"
export CROSS_COMPILE="aarch64-linux-gnu-"
export CROSS_COMPILE_ARM32="arm-linux-gnueabi-"

make mrproper
make ARCH=arm64 O=out ${1}
# make -j$(nproc --all) O=out LOCALVERSION=-android13-4-00050 Image 2>&1 | tee build.log
make -j$(nproc --all) O=out LOCALVERSION=${2} Image Image.gz 2>&1 | tee build.log
EOF

chmod +x ./build.sh
